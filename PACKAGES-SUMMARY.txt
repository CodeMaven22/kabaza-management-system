4. QUICK INSTALLATION (3 steps)
================================================================================

STEP 1: Clone Project
  $ git clone <your-repo-url>
  $ cd kabaza-management-system

STEP 2: Install Frontend
  $ npm install
  $ cp .env.local.example .env.local
  # Edit .env.local and set: NEXT_PUBLIC_API_URL=http://localhost:8000/api

STEP 3: Install Backend
  $ cd ../kabaza-backend
  $ python3 -m venv venv
  $ source venv/bin/activate    # macOS/Linux
  $ venv\Scripts\activate       # Windows
  $ pip install -r requirements.txt
  $ python manage.py migrate
  $ python manage.py createsuperuser

STEP 4: Run Both
  Terminal 1 (Frontend):
    $ cd kabaza-management-system
    $ npm run dev
    # Opens http://localhost:3000

  Terminal 2 (Backend):
    $ cd kabaza-backend
    $ source venv/bin/activate
    $ python manage.py runserver
    # Opens http://localhost:8000

================================================================================
9. TROUBLESHOOTING
================================================================================

Issue: "npm: command not found"
Solution: Reinstall Node.js from https://nodejs.org/

Issue: "python: command not found"
Solution: Reinstall Python from https://www.python.org/ or use python3

Issue: "Port 3000 already in use"
Solution: npm run dev -- -p 3001

Issue: "Port 8000 already in use"
Solution: python manage.py runserver 0.0.0.0:8001

Issue: "ModuleNotFoundError: No module named 'django'"
Solution: Make sure venv is activated: source venv/bin/activate

Issue: "Cannot find module 'next'"
Solution: Reinstall node_modules: rm -rf node_modules && npm install

================================================================================
                        STOPPING THE SERVERS
================================================================================

To stop all servers:

  Terminal 1 (Frontend):  Press Ctrl + C
  Terminal 2 (Backend):  Press Ctrl + C
  Terminal 3 (Celery):   Press Ctrl + C (if running)
  Terminal 4 (Beat):     Press Ctrl + C (if running)

Next time you want to run:
  Terminal 1: npm run dev
  Terminal 2: python manage.py runserver
  (Optional Terminal 3 & 4 for Celery if needed)
